# 原生图片与视频生成体验 · preview.2

## 操作流程

1. 打开 PC 的 Studio 手机连接服务，手机连接后选择真实项目。
2. 点击顶部「生成图片」或「生成视频」。两类入口分别显示对应工作流。
3. 填写提示词；需要参考图时进入「选择参考图片」，可按名称搜索、取消或选择图片。数量上限依工作流显示，首尾帧明确标注顺序。
4. 设置画面比例、像素量、视频秒数和采样步数。种子、INT8、电影 LoRA 等位于高级参数中。0 步表示使用 PC 工作流默认值。
5. 点击「下一步 · 确认生成」。手机先检查输入，PC 返回实际分辨率、步数、帧数和对齐后的时长；确认页可返回修改，此时尚未创建任务。
6. 点击「确认并加入 PC 队列」后跳到任务页。进度来自 PC 的真实节点事件，节点百分比不是总体百分比。
7. 完成图片后点击「查看生成图片」，或直接「用此图制作视频」；生成视频后点击「播放生成视频」。图片库和图片预览也提供制作视频入口，自动带入选定图片。

关闭未提交的生成表单会询问是否放弃；继续编辑保留输入。表单使用 Compose 状态恢复以支持 Activity 重建，但不作为跨应用退出的长期草稿。取消任务需要二次确认，已保存的素材保留。

## 实现边界

- APK 是 Kotlin / Jetpack Compose 原生界面；视频由 Media3 播放。
- PC 继续提供工作流目录、默认参数、输出尺寸计算、任务提交、推理和文件保存。客户端没有另建 ComfyUI 工作流。
- 客户端校验用于提示输入错误，PC 仍执行最终权限、路径、参数与 Agent 审阅检查。
- 本轮不调整手机设置，不清空应用数据，不推送 GitHub，不发布 APK。
- 保留改动前源码于 `local-data/android-ux-backup-20261022-192554/`，旧 APK 由构建脚本保存为带时间戳的 `.bak`。不通过删除项目或素材回滚。

## 未覆盖事项

本轮只实际生成一张 Qwen 图片和一段 H3 图生视频，未穷举其他工作流；首尾帧数量、种子边界等有单元校验，不等于全部工作流真机生成通过。横屏重建、长视频、断网恢复、生成中取消和大素材库仍需专项验收。本轮没有改动 Python 业务或桌面源码，因此未重复运行原有桌面回归套件。
