# Agent 连续生成：原因与建议方案（待决定，未实施）

适用版本：XY Studio v0.3.1 / v0.3.2。用户示例：先生成舞台，再把已有初音未来融入舞台，最后让合成场景动起来。

## 当前为何停在第一步

这与前端迁移或 DeepSeek Key 无关，当前控制器只实现了创建/修改后的有限接续，没有实现生成结果驱动的接续。

- `StudioService.review()` 确认 `generate` 后将任务加入队列，回传“尚未完成生成”，同时将 `batch.generated` 设为真。
- `_next_review()` 仅在 `not batch.generated` 时继续请求 AI，最多 4 轮。因此创建舞台可以接续到生成舞台，但第一项生成提交后停止接续。
- `_completed('job')` 保存结果并启动待执行队列，没有把完成状态、输出路径与用户剩余目标交给 Agent。
- Qwen 编辑参考必须是已存在的项目相对图片路径。下一步所需的舞台图片在第一步提交时尚不存在。仅让模型一次提出三项生成，会导致缺少参考或错误使用旧图。
- 场景资产只生成图片；视频要归属 `shots`。该示例还需要创建一个分镜，将初音未来和舞台关联，再把合成图片及视频保留在这个分镜内部。

本次没有在用户项目中重放该请求，也未取到这次完整工具日志。上面是代码已经证实的执行边界，可以解释用户反馈；模型该轮具体提出了哪些工具仍需原对话日志才能逐项复核。

## 难度

中等偏高。顺序生成的基础接续难度中等，可复用现有 Agent、Skill、任务队列、工作流和输出登记；可靠的取消、重启恢复、防止错用版本及重复提交是主要工作量。不是重新开发后端，也不是只改一段系统提示词。

不建议仅删掉 `not batch.generated`：那会在任务还未完成时再次询问 AI，增加轮询费用，仍无法保证新图已经可用。

## 建议第一期范围

增加可持久化的顺序计划，不做任意流程图或无限自主循环。保留现有单项审阅机制；新增计划模式，先展示完整步骤、目标素材、模型与每步参数。用户确认整份具体计划后，执行其已确认范围；改变目标、参考、参数或增加步骤需要重新审阅。

示例计划：

| 步骤 | 输出归属 | 工作流 | 必须满足的依赖 |
|---|---|---|---|
| 1. 生成舞台 | 新建舞台场景资产 | Qwen 文生图 | 用户确认舞台描述及图片参数 |
| 2. 初音融入舞台 | 新建分镜的图片版本 | Qwen 图片编辑 | 步骤 1 的确切输出版本、已有初音参考的确切版本；参考顺序与 prompt 的 image 标签一致 |
| 3. 让画面动起来 | 同一分镜的视频版本 | H3 图生视频 | 步骤 2 的确切合成输出，确认的动作、视频分辨率、时长、LoRA |

执行器监听原队列的完成事件：任务完成且结果落盘、输出登记到正确 ID 后，再解析下一步引用。通过新上下文请求 Agent 准备下一步所需提示词，但不得自行扩大已确认步骤或参数范围。第一期默认锁定每步输出版本，即使用户期间又手工生成同名素材，也不从“当前图片”偷换引用。

## 工程实现

1. 独立的 `PlanRunner` 状态机，由 Qt 主线程维护；GPU 任务仍通过 `StudioService.submit()` 和现有串行队列执行。状态包括待审阅、执行、等待任务、暂停、失败、取消、完成。
2. 计划写入项目目录的独立 journal（例如 `agent-plans/<plan_id>.json`），不改变 schema=1 和原资产 ID。保存用户目标、步骤、精确引用、审批快照、绑定 job ID / prompt ID、输出 version ID。
3. 将“步骤 1 输出”作为计划内部引用，在完成事件中解析为真实相对文件路径；不得提前提交不存在的参考。失败或找不到目标时停止，并保留具体原因。
4. UI 显示整个计划及每步状态，提供暂停、继续、停止。已运行任务只按确切 prompt ID 请求取消，不中断独立 ComfyUI 的其他任务；停止后禁止启动剩余步骤。
5. 恢复时查询原 prompt ID，输出登记沿用已有幂等逻辑。未知提交不自动重交；崩溃发生在回传结果前时，先对账再推进，避免生成两次。启动后要求用户明确恢复计划。
6. 将 Agent 准备失败和 ComfyUI 生成失败分别记录；限制步骤数、每步模型请求次数及修复次数，失败不无限重试。

## 验收

- 用示例完整执行舞台 → 合成 → H3，逐项核对图像输入路径、顺序、版本 ID 和结果归属。
- 在第一步失败、取消、暂停和完成事件重复到达时，后续不会误启动。
- 在提交后、输出下载后、步骤衔接时退出并重开，均不重复提交，能准确恢复或明确暂停。
- 执行中手工切换旧版本、生成另一版本、删除素材、切换项目时，依赖仍锁定或操作受到明确保护。
- 全程保留参数审阅、Skill 校验、取消/恢复及现有项目读写测试。

当前 DeepSeek 接口只接收文字和文件路径，不接收图片像素。完成事件能证明文件生成成功，不能证明初音融合自然或视频动作正确。第一期应保留最终人工审阅；自动视觉质检属于另一项能力，不能在本方案中假定已经具备。

本次只交付方案，不启用生成完成后的自动串联，也不改变当前生成审批权限。
