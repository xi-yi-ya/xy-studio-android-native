# Android 对话附件与桌面功能对照 · preview.4

本轮以实际 Vue 组件、Pinia 调用、Python LAN 白名单及原生源码为对照，不把界面入口等同于完整业务验收。继续使用 Kotlin / Compose；项目、推理、Skill 和密钥由 PC 管理。

## AI 参考图片与视频

创作页右下角进入 AI 助手，输入框上方新增：

1. **＋ 图片 / 视频**：在原生弹窗切换图片、视频，搜索并分页查询真实项目素材。点击即加入下一条消息的引用，已加入项目会标记，避免重复添加。
2. **从手机导入**：打开 Android 系统文件选择器；图片或视频上传到 PC 原项目素材库后加入 AI 引用。单文件上限 100 MB，支持现有 PC 接受的 PNG/JPEG/WebP、MP4/WebM/MKV；不申请全盘读取权限。
3. 输入框上方显示附件卡片和角色/场景/分镜引用。附件可点击预览、逐个移除，或清空下一条消息的引用；移除引用不会删除文件。
4. 仍需用户点击「发送」。添加附件不会自动调用 DeepSeek 或提交生成；AI 建议仍经过现有操作审阅与生成参数确认。

**能力边界与桌面一致：**当前 DeepSeek Agent 使用文件引用、项目描述和文字，没有直接接收图像像素或视频音轨。因此可把真实图片提供给下游生成工作流，但添加视频不代表已完成视频内容识别，也不代表当前 H3 工作流支持视频作为推理参考。没有为补齐手机 UI 更改模型能力或声称新增视觉理解。

## 修改与回滚

新增 `ChatAttachments.kt`、`MediaPicker.kt`、`WorkspaceActions.kt`、`LibraryFilters.kt`，扩展原有 ViewModel 与页面；Python/桌面业务不变，PC 的路径授权、串行写入、版本冲突检查和审阅逻辑继续生效。

修改前源码备份：`local-data/android-chat-media-backup-20261022-203519/`。构建脚本自动保存旧 APK 的时间戳 `.bak`。仅恢复源码并重建即可回滚，不删除用户项目、已有素材或手机应用数据。代码、APK 均仅本地保留。

测试证据目录：`demo/evidence/android-chat-media-20261022/`。设备测试只操作明确创建的 QA 条目与真实媒体副本，不发送 AI 消息或生成任务；结束时恢复测试前的 AI 引用。
