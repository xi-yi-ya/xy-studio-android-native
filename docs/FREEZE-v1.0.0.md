# XY Studio v1.0.0 冻结基线

冻结对象是首个正式 Windows 桌面版本，版本号为 `1.0.0`，源码标签为 `v1.0.0`。用户在本轮要求修复完成后冻结；本记录不设置额外账户权限，不锁定主分支。

## 范围

冻结包含 Vue 正式界面、Python 后端、内置指南快照、工作流适配、原项目兼容、任务/历史/审阅功能，以及本轮进度、历史图片、用户可读 AI 信息和视频事件修复。

不包含新的自动视频串联执行器；不把本机 ComfyUI 模型、用户项目、API Key、虚拟环境和 QA 项目打入发布包或源码。密钥和模型仍由用户本机管理。

## 定位

- Windows 包：`releases/v1.0.0/XY-Studio/XY-Studio.exe`，需保留整个目录。
- 可分发压缩包：`releases/v1.0.0/XY-Studio-v1.0.0-Windows.zip`。
- 包校验：同目录 `XY-Studio-v1.0.0-Windows.zip.sha256`。
- 源码：原私密仓库的 `v1.0.0` 标签，不随未来主分支变化。
- 验收：[VALIDATION-v1.0.0.json](VALIDATION-v1.0.0.json)。
- 交付、截图与边界：[RELEASE-v1.0.0.md](RELEASE-v1.0.0.md)。
- 学习资料：[Java 对照开发文档](JAVA-DEVELOPER-GUIDE.md)。

发布包提供独立的文件哈希清单，便于核对实际交付内容；哈希不是数字签名，也不代替测试。旧版本和本轮候选目录保留，未覆盖用户项目。

## 后续维护

新修复或功能使用新的版本号、源码提交、版本标签和发布目录。不得复用 `v1.0.0` 标签覆盖已有包。保留本版验收结论及其已知边界，新增验收写在新版本中。

回退时先保存并关闭新版，再在旧版打开项目，避免两个实例同时修改。若未来版本确实修改项目格式，必须先保留项目备份并完成迁移兼容验证；本版 schema 仍为 1。
