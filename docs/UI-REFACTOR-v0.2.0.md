# XY Studio v0.2.0 UI 重构交付

## 技术方案

继续使用 Qt Widgets + QSS，未引入 WebEngine。业务控制仍在 Studio，独立展示组件通过 ID 和 Qt 信号请求控制器操作。ComfyUI 图构造、DeepSeek 工具权限、参数审阅、队列及任务 journal 不变。

## 文件清单

| 文件 | 修改内容 |
| --- | --- |
| studio/theme.py | 统一暖灰白背景、字体、字号、圆角、边框、按钮、导航及状态颜色 |
| studio/workspace.py | 角色/场景自适应网格、素材/镜头卡片、预览、折叠、版本摘要、实际参考图、时间轴 |
| studio/ui.py | 左侧导航与项目概览、嵌入任务管理、页面组装、选中状态/AI 上下文、窗口适配及旧功能连接 |
| studio/media.py | 从实际视频读取时长，按文件大小/修改时间缓存 |
| studio/__init__.py | 版本 0.2.0 |
| tests/test_workspace.py | 项目生命周期、绑定、历史、恢复、时间轴、长文本、100 卡片等回归 |
| tests/test_media.py | 实际视频时长元数据测试 |
| scripts/validate_ui_layout.py | 独立进程 DPI/窗口尺寸检查 |
| README.md、docs/CHANGELOG.md、docs/VALIDATION.md | 启动说明、版本变化与验证记录 |

## 交互与数据兼容

- 左侧项目概览、角色资产、场景资产、分镜工作区、任务与历史、全局设置；设置仍通过原生对话框编辑。
- 角色/场景共享卡片布局，保留编辑、生成、导入、删除、历史、发送给 AI 和双击查看图片。
- 镜头包含描述、关联素材、最近生成的真实参考图、分镜图、视频首帧与播放入口、任务状态、版本摘要和完整历史入口。历史始终使用原 ID，不创建额外镜头。
- 时间轴同步卡片及 AI 当前对象。已有视频读真实时长；未生成任务按合法帧数显示预计值；没有任务则显示待定。
- AI 审阅和取消机制不变；选中卡片自动传入 selected_ids，附加素材可保留或清除。侧栏隐藏不会清空上下文。
- schema 仍为 1，已有素材及任务 ID 不变。镜头自定义名称复用既有 original_name 字段；自动编号保留。
- 折叠与当前选择是窗口状态，不写入项目，不影响旧版打开。取消/恢复查询/打开结果/再次生成入口均保留。

## 验证

- 68 项测试通过，原有测试全部保留；未通过删减功能、跳过测试或屏蔽异常取得通过。
- Qt 模拟 100% / 150% / 200% DPI，每档检查 900×620、1000×720、1440×900、1920×1000 逻辑窗口及三个工作页面，未发现横向溢出。
- 100 张长名称/长描述卡片测试通过；小窗口自动单列，较宽窗口增加列数；分镜内部在窄空间改为纵向排列。
- 真实 DeepSeek Flash → 创建 → 接续生成 → 参数确认 → Krea 0.1 MP / 4 步 → ComfyUI 完成 → 项目历史归属通过。证据在 local-data/v020-live-report.json（不提交密钥或用户项目）。
- 项目保存重开、journal 完成结果恢复、重复恢复不重复添加版本、选中素材传给 AI、模态审阅及取消流程均有回归覆盖。

## 已知限制

- 时间轴只定位镜头，不支持拖拽剪辑、转场、音轨或导出成片；符合本次轻量范围。
- 视频首帧在卡片内展示，点击“播放视频”打开原生播放窗口，未实现卡片内多路同时播放。
- 100 张卡片已验证；未实现超大项目的虚拟化列表，数千素材时需进一步性能测试。
- DPI 为 Qt 缩放模拟及当前 Windows 屏幕验证，未实测在不同 DPI 的物理双显示器之间拖动。
- 本轮未重新进行 H3 GPU 视频生成，视频预览/时长读取使用已有真实 H3 输出；视频参数和图构造由既有测试覆盖。
