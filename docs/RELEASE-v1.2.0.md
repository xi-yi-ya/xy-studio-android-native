# XY Studio v1.2.0 — 先生成入库，再手动选用

本版把生成结果与项目资产分开：图片、编辑和放大结果进入图片库，视频进入视频库。用户选好结果后，才把它添加为角色、场景或分镜媒体。仅生成不会替换现有图片，不会创建空角色或空镜头，也不会增加已有资产的版本。

本版在本机交付。按用户要求，未上传、未推送、未发布远端版本。旧版本目录保留，修改前的源码快照保存在本机 `local-data/v120-source-before.zip`；用户项目与原始媒体没有用验收项目覆盖。

## 启动与操作

运行 `releases/v1.2.0/XY-Studio/XY-Studio.exe`，或将 `XY-Studio-v1.2.0-Windows.zip` 解压后运行其中的 EXE。保留整个 `XY-Studio` 文件夹；模型和 ComfyUI 仍使用本机安装，未打包。现有 Windows 凭据和 ComfyUI 设置继续使用。

1. 顶部“生成图片 / 生成视频”打开统一参数窗口，AI 助手收起时仍可操作。
2. 图片库与视频库包括导入原文件、全部生成结果和旧历史。可搜索、筛选、分页、预览、查看生成参数和参考图。
3. 角色/场景入口改为“添加角色 / 添加场景”：从图片库选图，填写可选名称，再确认。不填写沿用图片名称；取消不创建条目。卡片展示图片和名称，保留替换、历史、发送 AI 与删除。
4. 分镜保留故事、描述、编号、关联素材、时间轴及折叠。图片和视频入口改为添加/替换，不在镜头上直接生成。手动选用后才登记该镜头的历史版本。
5. 不满意时在素材库或任务历史中“再次生成”，恢复原提示词、参数和原有序参考图。修改未确认时不覆盖原记录。想以当前结果作为输入时，明确使用“基于此图继续编辑”或“用此图生成视频”。
6. 图片/视频库为空时提示先生成或导入；搜索无结果提示清除筛选，不误称整个库没有素材。

## AI、参考图和拖拽

“让这张图片动起来”可以直接提出 H3 图生视频审阅。使用本轮引用的真实图片，不再要求先创建分镜或补生图片。生成仍须用户在参数窗口确认；本版没有实现一条指令自动等待“生成舞台→合成人物→生成视频”的多阶段串联。

参数审阅显示有序参考图的实际缩略图、名称及编号，可以点击放大、上下排序或移除。原文件缺失时明确显示“原文件缺失，请重新选择”，禁止放大；提交时后端拒绝请求，不产生任务。

内部图片可以拖入 AI，准备下一条消息的附件，支持逐项移除。Windows 本地图片/视频可以拖入桌面窗口：库中按类型导入，AI 区同时导入并引用，生成参考区只接受图片。原文件复制到项目，保持原字节；拖入不自动发送消息、不自动生成、不自动创建资产。内部拖拽包含项目身份，拒绝跨项目文件引用。

AI 对话、联网、模型选择、按需 Skill 和逐项审阅沿用原后端。DeepSeek 当前只接收文字及素材元数据，没有收到图片像素；不能把它写出的描述当作实际看图核验。Qwen 与 H3 才接收生成参考原图。

## 数据与实现

继续使用 Vue 3 + QWebEngineView + QWebChannel + 现有 Python 后端，没有迁移业务逻辑到 Java，也没有新增独立 Python 后台服务。

- `project.json` 继续 `schema=1`，旧角色、场景、镜头 ID 不变；旧描述从资产卡片界面移除，但保存在原项目数据中。
- 新任务 `target=__library__`，输出记录仍在原任务 `outputs`；兼容调用传入旧目标时，可选 `origin_target` 仅用于追溯与默认参数回填。
- 旧已完成任务与版本归属保留。恢复旧未完成任务时增加可选 `library_only=true`，保留原 ID/target，但新输出只入库；不会趁恢复任务自动替换卡片。
- 手动选用引用库中原文件，不再复制一份；库内身份、生成记录和角色/镜头名称独立。同一资产再次选用同一文件复用原版本。
- 导入名称通过可选 `media_names` 保存；没有这个字段的旧项目继续正常打开。密钥不写入项目、文档或 Git。
- 保存、锁定项目、任务排队、取消、恢复查询、真实节点进度、H3 视频兼容预览及原工作流参数沿用原实现。

Java 学习文档见 [JAVA-DEVELOPER-GUIDE.md](JAVA-DEVELOPER-GUIDE.md)，已更新生成/选用分离、接口、版本恢复和桌面拖拽的 Java 概念对照。示例是局部转译，不能作为一套可编译的 Java 应用使用。

## 已知边界

- 生成质量仍由图像/视频模型决定，需要用户挑选。这里只验证低规格短视频，不保证任意尺寸与时长均不爆显存。
- 新版能读取旧项目；回退旧 EXE 会恢复旧版交互和恢复任务行为，不应使用旧版继续执行新版未选用流程。切换版本前关闭正在编辑同一项目的实例。
- 大体积视频导入复制目前在桌面主线程执行，可能短暂阻塞界面；没有伪造导入进度。
- H3 视频/音频参考、成片拼接、复杂剪辑和 Agent 自动连续生成仍未新增。
- 拖拽验收包含真实 Qt 事件到 Vue/后端导入与内部拖拽；不将程序注入的本机事件描述成已用资源管理器手工拖拽验收。
