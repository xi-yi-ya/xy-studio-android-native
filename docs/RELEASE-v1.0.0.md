# XY Studio v1.0.0 · 首个正式冻结版

本版在已验收的 Vue 3 桌面界面和原 Python 后端基础上，完成历史图片、用户可读 AI 输出及真实数字进度验证。冻结后新增功能或修复另开版本，不覆盖本版源码标签和发布文件。保留旧项目格式、资产 ID、凭据存储、生成队列及旧版回退目录。

## 本次完成

- 真实数字进度在全局任务、角色/场景卡片、分镜和任务列表显示。按授权重启 ComfyUI 后事件推送恢复；真实图片与短视频逐次核对百分比、步数及 UI 测量值。没有改动 ComfyUI 代码或工作流。
- 任务历史显示每次实际生成的图片、视频封面和多输出结果，可点击放大。“查看结果”仅打开该次输出；切换当前版本不会改变旧记录，删除条目后已保存的任务输出仍可预览。
- 聊天、操作审阅和生成详情改为中文可读信息，不展示内部 Skill JSON、指南文件、工具参数对象、原始参考路径或任务 ID。联网来源和错误提示保留。工具调用的空白或英文说明用中文操作摘要呈现，用户文字和普通创作内容保留，原始模型记录不改写。
- 修复补读指南后只返回提示词的问题：已经提出的生成操作补读指南后继续走工具建议路径，仍经过现有用户审阅。普通聊天不强制工具，不扩张权限。相关接口支持见 [DeepSeek 官方说明](https://api-docs.deepseek.com/api/create-chat-completion/)。
- 按用户决定，不开发一句话自动串联“舞台 → 合成 → 视频”的依赖执行器。保留原有逐项建议、审阅与生成能力。
- 修复切换项目或关闭预览后旧视频事件读取已卸载控件导致的报错。事件只更新当前播放器，切换来源重新初始化时长；补充迟到事件回归，所有桌面测试都检查页面没有未处理错误，未隐藏错误提示。
- 交付 [Java 对照开发文档](JAVA-DEVELOPER-GUIDE.md)，解释现有 Python 后端的职责、数据、任务、Agent、通信和生命周期。Java 片段用于学习，不替换实际后端。

## 启动与兼容

本机双击 `releases/v1.0.0/XY-Studio/XY-Studio.exe`。发布包解压后保留整个 XY-Studio 文件夹，先启动本机 ComfyUI，默认端口 8188。DeepSeek 密钥继续保存在 Windows 凭据管理器，正式包不附带任何密钥。

旧版若正打开同一项目，先关闭旧版，再在新版打开。项目 schema 仍为 1；新增 `results` 是前端展示 DTO，不是修改项目文件格式。旧模型配置和原始生成资产保留。v0.2.0、v0.3.1、v0.3.2 以及本轮候选目录均保留，供回退和核对。

架构保持 Vue 3 + QWebEngineView + QWebChannel 的正式桌面实现，Python 后端在应用进程内运行；本机媒体服务只提供文件，不引入独立业务 sidecar。正式迁移说明见 [v0.3.0](MIGRATION-v0.3.0.md)。

## 已知边界

进度是当前处理步骤的百分比，切换步骤可能重置，不是整项任务预计剩余时间。高分辨率、长时长的视频没有扩大实测范围。ComfyUI 未返回测量值时只显示阶段和查询状态，不估算进度。

AI 接收文本及路径，没有图片识别能力；本次技术验收不代表图像融合、人物一致性或视频动作达到创作验收标准。Windows 原生文件选择器的人工点选沿用既有手动复核边界，自动回归覆盖 Qt 控件返回和后续导入流程。

此次已验证空闲状态正常退出；生成中退出按既有日志和恢复查询设计处理，不误关 ComfyUI，本轮没有新增 GPU 中断/断电恢复压力测试。新的自动视频串联功能明确不在冻结版本中。
