# XY Studio v0.3.3

这是本轮开发修复记录，未作为单独正式版本发布。最终完成并冻结为 [v1.0.0 首个正式版](RELEASE-v1.0.0.md)，启动和最终验收以该文档为准。

## 交付内容

- 任务与历史页直接展示每次生成的实际图片、视频封面和多输出结果。点击可放大查看；“查看结果”仅打开对应任务的输出。角色、场景、分镜的历史仍归属原 ID，不用当前图片替换旧记录。条目删除后，其已保存的任务结果仍可预览。
- 聊天区不再显示 Skill / 文件路径 / 活动 JSON。联网仍展示可点击来源，资料获取失败仍有提示。旧聊天中明确的内部 metadata 转为中文说明；空白或英文工具说明显示为中文操作摘要，普通创作文本、创作 JSON 和用户原文保留。磁盘中的原始 Agent 内容、工具参数和活动日志不改写。
- AI 操作确认改成名称、类型、描述、关联素材等中文字段。生成参数、任务详情和版本详情改为可读信息，不展示原始对象、任务 ID 或引用路径；取消、恢复、再次生成、使用版本及打开原文件均保留。
- 真实进度显示当前处理步骤的百分比与步数；准备、解码或保存阶段没有测量值时不推算百分比。按用户授权重启 ComfyUI 后，原事件推送阻塞解除。没有修改 ComfyUI 的代码或工作流来完成这次修复。
- 按用户决定，不开发一句话串联“舞台 → 合成 → 视频”的自动执行计划。原有逐项操作与审阅能力保留，没有启用新的自动执行权限。

## 兼容和结构

Vue 页面沿用已有布局和风格。新增 `ChatSources.vue`、`GenerationDetails.vue` 负责展示；`studio/presentation.py` 负责中文呈现，原业务数据仍由既有服务与存储维护。任务 DTO 增加 `results`，项目 schema=1、原素材 ID、已有相对文件路径、API Key 存储及生成队列格式不变。

## 验证

- Python 全量测试：92 项通过，未删除原测试。文件对话框测试驱动补了真实文件名输入及有上限的异步重试，仍使用实际 QFileDialog 返回结果，未 mock 返回值。
- 真实 Qt WebEngine 桌面回归：11 项通过，覆盖旧项目、取消选中、图片放大、任务状态、恢复入口、视频播放、审阅、中文显示、历史图片加载、准确的任务归属及布局适配。
- ComfyUI 重启前队列为空，既有内存历史已备份到本机忽略目录。重启后真实生成验收：角色图片、场景图片（含同素材第二个手工任务）、分镜图片、H3 图生视频共五项任务成功。使用 0.1 MP；H3 设置 0.5 秒，实际对齐为 22 帧，避免高规格显存压力。
- 逐次对比 WebChannel 状态与界面 `aria-valuenow`，真实采样过程返回多个不同测量值。节点 100% 不作为任务完成条件，输出保存和原条目版本登记均检查。
- 真实 DeepSeek：从原凭据管理器读取密钥，按需读取 Qwen 指南，准备图片编辑操作；聊天没有内部字段，参考列表没有原始路径，用户取消后没有新生成任务。没有调用自动视频串联，也没有为界面测试产生视频 Agent 执行。
- 修复补读指南后仅返回提示词、却声称可在参数窗口执行的问题。仅在模型已提出生成工具而需要补读指南时，后续修正保持在工具建议路径上；仍经过原权限检查及用户审阅。普通聊天不强制调用工具。使用的非思考模式支持该参数，参见 [DeepSeek 官方接口说明](https://api-docs.deepseek.com/api/create-chat-completion/)。
- Windows 正式版打包、回归和真实进度复验结果见 [v1.0.0 验收文件](VALIDATION-v1.0.0.json)，不包含 API Key。

## 已知边界

进度百分比表示当前处理步骤，可能随进入下一步骤而重置，不是整项任务剩余时间估计。极高分辨率和长视频没有扩大验证范围。ComfyUI 事件不推送时仍保留阶段与 HTTP 查询，不伪造进度。

应用不替用户判断图像融合或视频动作是否自然；DeepSeek 当前只接收文字和路径，最终创作效果仍由用户审阅。Windows 原生文件选择器的人工点选仍沿用此前的手动复核边界，自动测试覆盖 Qt 对话框返回及完整后续导入。
