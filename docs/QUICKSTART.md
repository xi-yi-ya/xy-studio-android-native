# XY Studio：下载后开始使用

这是大学生毕业设计阶段的个人项目，后续更新随缘，没有固定维护计划。

## 下载什么

- **推荐：[夸克网盘：XY Studio＋ComfyUI](https://pan.quark.cn/s/050569c33d82)**。作者已将 XY Studio 完整压缩包放进同一个分享，选择 `XY-Studio-v1.2.1-Windows.zip` 和 ComfyUI 配套环境下载。分享名称仍为「comfui」。
- [GitHub Releases 备用下载](https://github.com/xi-yi-ya/ai-story-studio/releases/latest)：也可在 Assets 中下载同一 Windows 程序包；不包含 ComfyUI。Source code 是给开发者使用的源码。

两个压缩包分别完整解压到可写目录。XY Studio 已包含运行环境，不用另装 Python、Node.js 或前端依赖；ComfyUI 负责模型运算，需要与其要求匹配的显卡、驱动和可用内存/显存。模型与插件不打进 XY Studio 的 ZIP。

## 第一次运行

1. 打开 ComfyUI 配套包自带启动器，启动 ComfyUI；等待服务启动完成。默认地址应为 `http://127.0.0.1:8188`。如实际使用其他地址，在 Studio 设置里修改。
2. 双击 XY Studio 文件夹里的 `XY-Studio.exe`。不要只复制 EXE，旁边的 `_internal` 文件夹也必须保留。
3. 新建一个项目文件夹。可放在文档盘；不要把项目保存在未来可能替换的应用安装目录里。
4. 顶部“生成图片” → 选择工作流、填写提示词 → 检查参数 → 加入生成队列。第一次可选择较低分辨率；视频先用短时长、小分辨率验证。
5. 图片库 / 视频库中查看结果，满意后再“选用素材”，加入角色、场景或分镜。外部素材用导入按钮，当前版本不支持拖拽。

## AI 助手（可选）

在设置里填写你自己的 DeepSeek API Key。它保存在本机 Windows 凭据管理器，不随项目共享。AI 服务的联网和对话按服务商规则计费。没有 Key 时仍可手动生成、导入和管理素材。

对 AI 说“生成一张……”会提出参数审阅；需要你确认才排队。修改已有图片时先在图库点“发送给 AI”。生成结果先入库，不自动创建或覆盖角色、场景和分镜。

## 常见情况

| 情况 | 处理 |
| --- | --- |
| 无法连接 ComfyUI | 先确认浏览器能打开本机 ComfyUI，核对 Studio 设置中的地址和端口 |
| 缺节点或模型 | 使用匹配的配套环境，按错误中给出的名称检查模型/插件；不是随意导入一份工作流就能兼容 |
| 显存不足 | 降低分辨率；视频缩短时长。是否能够运行取决于模型与硬件，不只取决于图片大小 |
| 双击 EXE 不工作 | 确认已完整解压、`_internal` 存在；不要在 ZIP 内直接运行 |
| 没有 DeepSeek Key | 用顶部生成入口手动输入提示词即可 |
| 素材不能删除 | 如果被当前资产/分镜或未完成任务使用，先解除使用或完成/取消任务 |
| 删除后空间没有减少 | 当前删除是项目回收站，保留原文件和历史，可恢复；不做磁盘清理 |
| 网盘无法打开或文件缺失 | 网盘分享由作者维护；仓库不自动下载模型，也不提供失效链接的替代镜像 |

退出 Studio 不会关闭你独立启动的 ComfyUI。再次使用先启动 ComfyUI，再打开 Studio。
