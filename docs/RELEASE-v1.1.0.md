# XY Studio v1.1.0

修复发送给 AI 的引用无法取消的问题，加入完整的当前项目图片库、视频库及 AI 只读查询，并按用户提供的两份 Qwen 工作流修正图片生成与编辑。沿用已验收的 Vue 桌面设计和 Python 业务，不迁移项目数据，不覆盖冻结的 v1.0.0。

## 完成内容

- 左侧新增图片库、视频库。汇总导入文件、所有已保存的生成输出、历史版本、未关联参考，以及删除条目后保留的生成文件。缩略图和兼容视频缓存不重复计数。搜索名称、关联对象与提示词，支持来源、归属、排序和分页；显示实际尺寸、时长、记录时间、提示词，支持预览、定位原卡片和打开原文件。缺失/损坏文件显示错误，不用演示图替代。
- 素材库可导入图片和视频；视频导入作为查询和播放素材，未扩张 H3 的参考输入。生成窗口增加完整图片库选择器，可以选旧版本或未关联图片；原来的当前素材选择、导入及排序仍保留。
- AI 当前讨论对象、固定对象引用、具体图片/视频引用分别提供取消按钮，并可清空全部。没有选中卡片时仍可取消引用。取消会从下一轮上下文移除，不删除文件，不撤回已发送请求或对话历史。
- DeepSeek 增加 `query_image_assets` 和 `query_video_assets` 两个只读工具，支持搜索、筛选、分页并访问全部保留的生成记录。只返回元数据，未加入视觉识别能力；写操作仍经过原有审阅。查询本身不提交图像模型任务，但 DeepSeek 对话仍有正常 API 费用。每轮最多 12 次素材查询、8 次主模型请求，超出时明确提示。
- 图片生成默认 Qwen T2I，沿用指定文件的 BF16 底模/编码器/VAE、40 步、CFG 1、Euler/Simple、16-bit PNG 和 8 像素分辨率选择。默认 6.6 MP、16:9，可在确认窗口调整，低规格实测不代表 6.6 MP 显存验收。界面预计输出考虑 Qwen VAE 的二次尺寸对齐。Krea2 仍可选，历史任务重试保持其原工作流。
- Qwen 编辑默认 INT8，补上缓存节点，不再居中裁剪主参考图；按指定文件连接原始有序参考，默认使用编码器的第一张图尺寸 latent。界面可切换到明确的自定义画布模式。编辑仍保存指定文件的 8-bit PNG。种子、提示词、参考及输出前缀使用实际用户参数与项目隔离目录，不复制示例中的私人素材和提示词。

## 兼容与启动

双击 `releases/v1.1.0/XY-Studio/XY-Studio.exe`，保留整个文件夹。先启动本机 ComfyUI（8188）。原 DeepSeek Key 继续使用 Windows 凭据管理器，无须重新填写。

项目 schema=1、资产 ID、历史路径和已有原文件保持兼容。素材库索引即时派生，不写新资产 ID。编辑尺寸选项保存于任务的可选顶层字段，避免在旧 `Generation` 参数中加入无法识别的字段；旧 v1.0.0 可以打开新版保存的项目。回退前先关闭当前版本，避免同时编辑同一项目。重试旧编辑任务会使用修正后的参考处理逻辑，已有输出不改变。

Qwen 底层节点和模型文件须存在于本机。程序没有改写两份来源 JSON 或 ComfyUI 安装文件。最新来源摘要见 [工作流配置与哈希](workflow-sources-v1.1.0.json)，首个冻结版继续保留在 `v1.0.0` 标签和原发布目录。

## 验收

详细结果见 [验收记录](VALIDATION-v1.1.0.json)。包含 Python 全量回归、实际 Windows EXE 界面回归、旧项目副本、真实 Qwen 编辑与 BF16 文生图、真实 DeepSeek 查询/编辑审阅，以及正常退出进程检查。没有以 Mock Data 或模拟百分比替代这些实测。

109 项 Python 测试、15 项正式 Windows EXE 桌面回归通过。源码和正式包各实际生成 3 张 Qwen 图片；正式包验证 448×256 / 320×320 的 INT8 编辑及 608×352 的 BF16 文生图，PNG 原文件位深分别为 8/8/16。全局及卡片数字进度与实际节点步数一致。DeepSeek 完整资产查询、按需指南、中文编辑审阅和取消不排队通过；旧 v1.0.0 EXE 打开新版项目副本、历史预览和保存通过。6 个本轮应用进程全部正常退出，独立 ComfyUI 继续运行。

本轮新增真实生成只使用低分辨率，核对原图尺寸与 PNG 位深、全局/卡片数字进度及原卡片历史归属。H3 业务未改动，视频播放和旧结果用 v1.0.0 已真实生成的文件副本回归；本版不把这些副本称为新生成视频。

## 边界

素材库范围是当前项目内部已保存的原文件及项目记录，不扫描整个磁盘，也不能自动取回仅存在于 ComfyUI 外部输出目录的文件。删除条目保留文件；如果实际文件已被手工删掉，只保留缺失提示。

AI 查询文字和元数据，不会观看视频。取消引用不会让模型忘记旧聊天，也不阻止用户主动让 AI 查询完整项目。视频参考、一次对话自动串联成片、复杂剪辑未新增。数字进度仍是当前步骤的测量值，不是总剩余时间；很快的步骤可能在一次界面刷新间完成。

未扩大高分辨率/长视频/断电压力测试范围。Windows 原生文件选择器仍保留人工点选复核边界，自动测试覆盖返回值、校验和真实文件导入。图像融合质量不代替作者验收；16-bit 文件保留在项目中，界面使用普通浏览器显示。

## 主要修改文件

后端：新增 `studio/asset_library.py`；修改 `service.py`、`deepseek.py`、`workflows.py`、`comfy.py`。前端：新增 `MediaLibrary.vue`；修改 `App.vue`、`AssistantPanel.vue`、`GenerationForm.vue`、`GenerationDetails.vue`、Pinia store、类型与样式。Python/桌面回归、两份显式真实测试脚本、版本信息、来源摘要、开发文档及截图一并提交；未纳入用户另行添加的格式化配置。
