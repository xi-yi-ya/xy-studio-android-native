# HR 演示录制方案（60–90 秒）

当前手机版本为 `1.2.1-native-preview.4`：暖白青蓝界面，首页 / 创作 / 素材 / 任务四栏导航，AI 助手从创作页悬浮入口进入全屏。界面真机截图在 `demo/evidence/android-design-20261022/screenshots/`，记录见 `docs/ANDROID-MOBILE-DESIGN.md`。此前真实图片与视频生成证据仍在 `demo/evidence/android-ux-20261022/`，操作见 `docs/ANDROID-GENERATION-UX.md`；生成入口现在位于首页和创作页。

演示的是 Kotlin + Jetpack Compose 原生 Android 客户端、Python LAN 服务和真实 ComfyUI。手机录屏由 Owner 真机完成。自动化测试截图按实际来源标记“iQOO 9 真机”或“PC 联调”，不能将 PC 联调描述为真机结果。

建议准备：同一 Wi-Fi、充电手机、PC LAN 控制窗口、ComfyUI 浏览器队列、一个已授权的真实项目。先运行完整流程确认模型已加载，再录制；实际等待很长时剪掉中间等待，并保留时间跳转说明，不能将生成延时伪装成实时速度。不要录到连接密码或 API Key，连接后直接展示已记住设备的自动连接。

| 时间 | 画面与操作 | 要证明的内容 |
|---|---|---|
| 0–8 秒 | PC Studio 侧栏“手机连接”启动服务；手机打开应用自动连接，出现“已连接 PC”（遮挡密码） | 内置服务、本机局域网和设备记忆 |
| 8–20 秒 | 手机项目列表，打开真实项目；浏览角色、分镜、图片库 | 同一份 PC 数据，不是静态原型 |
| 20–34 秒 | 手机“生成图片”，展示提示词、模型、种子与步数，确认加入队列 | 原生参数界面真正发起任务 |
| 34–43 秒 | 切到 PC ComfyUI 队列，显示该次任务的 prompt ID；手机显示真实节点进度 | 请求到达本机 GPU 后端 |
| 43–55 秒 | 手机打开生成图片；生成视频时选择刚生成的图片作为参考，检查参数并提交 | 图片到视频的真实素材链 |
| 55–70 秒 | PC 视频任务运行；手机显示节点与步数；必要时明确快进等待 | 实际进度同步，无伪造百分比 |
| 70–83 秒 | 手机视频库打开最新结果，点击播放，画面运动且播放时间增加 | 原生 Media3 播放真实结果 |
| 83–90 秒 | PC 项目资产与手机对照；展示源码目录或一句技术栈说明 | Compose + Kotlin / HTTP + WS / Python + ComfyUI |

录制操作：

1. 按 `docs/ANDROID-NATIVE.md` 启动 LAN 服务并授权项目。手机安装原生 APK。
2. 在 PC 浏览器打开 `http://127.0.0.1:8188` 的队列面板。不要开放 8188 给手机，也不要让浏览器自行提交演示任务。
3. 图片生成用明确、短的构图提示，参数以 PC 模型实际承受能力为准。记录确认后的种子、规格、prompt ID。
4. 图生视频参考刚生成的图片，保持短镜头和简单动作。手机参数审阅与 PC jobs 文件应能对应。
5. 若网络中断，展示自动重连和任务继续存在；不要为了录屏反复提交重复任务。
6. 录屏结束后在 PC 撤销设备授权或停止服务。保留原始录屏、项目任务日志和最终生成文件。

`evidence/pc-lan-live.json` 来自真实 LAN HTTP/WebSocket 调用，包含实际 ComfyUI prompt ID、输出相对路径和测得的节点步数。它说明 PC 联调结果，不表示 Android 真机通过。低步数联调素材用于技术验证，不作为最终画质样片。

`evidence/iqoo9-native-live.json` 和 `evidence/iqoo9/` 来自 iQOO 9 真机；图片及视频任务由原生 UI 提交。`08-native-playback-over-one-second.png` 显示实际播放到 1.288 秒。`evidence/desktop-lan-frozen.json` 单独记录 Windows r3 冻结包按钮启动、项目读取和退出停止服务的验证，不混同为新的真机生成测试。

## AI 附件补充镜头

在创作页打开 AI 助手，点击「＋ 图片 / 视频」，分别选取真实项目图片和视频，完成后展示输入框上方的两张引用卡片；点图片或视频可预览，点移除只取消引用。随后可演示「从手机导入」打开系统文件选择器。不要把添加附件剪成已发送 AI 或已完成生成。测试记录与桌面对照见 `docs/ANDROID-DESKTOP-PARITY.md`。
